# 逆塔防玩法演示

基于《逆塔防游戏策划案》，采用最新确认的施工、暂停、道路循环顺序与胜利规则。

## 运行

- Windows 演示：`Builds/ReverseDefenseDemo/逆塔防演示.exe`。
- Unity 2022.3.62f3：打开 `Assets/Scenes/ReverseDefenseDemo.unity`，点击 Play；或使用菜单「演示 → 逆塔防 → 打开并运行」。原来的 SampleScene 也可以直接 Play。
- 界面在运行时生成。所有文字使用 `UnityEngine.UI.Text`，没有使用 TextMeshPro。中文默认使用 Windows 的微软雅黑；也可在 DemoController 的 ChineseFont 中指定中文 Font。

## 操作

- 拖拽卡牌到网格，或点击卡牌再点击网格。
- R 键或「旋转选中卡牌」旋转多格卡。
- 右键或 Esc 取消卡牌选择 / 关闭地块详情。
- 空格或「免费暂停」切换手动暂停；没有资源消耗。
- 第一次放置后进入整批施工，可以继续放多张卡，临时允许未闭合支路。
- 「完成施工」统一验证；失败退回本批全部卡牌，恢复原地图与手牌顺序。
- 「撤销整批」主动取消本批施工。
- 速度按钮切换 1、2、4 倍。
- 每两圈出现一位首领；击败第三位后结算胜利，可以继续当前地图或重新开始。

## 一分钟演示

1. 进入地图，观察角色沿金色主循环行走。
2. 把「三格转角」以默认朝向放在 `(4,7)`，此时自动暂停，路线尚未完成。
3. 把「四格转角」以默认朝向放在 `(6,7)`，组成顶部绕路。
4. 点击「完成施工」，原主道路仍为 16 格；角色先走完这一圈，再进入新增的 20 格拼接闭环。两条路线全部走完后重新开始主道路。
5. 把矿场 / 恢复营地 / 怪物营地放在紧邻道路的空格，再提交。角色经过时触发收益、恢复或战斗。
6. 要演示失败退牌，重新开局，只放步骤 2 的一张道路卡，然后提交。
7. 切换到 4 倍速度，可较快观察首领战与胜利选项。

## 已落实的规则

- 原主道路始终保留并优先行走。角色完成原主道路一圈后，按上、下、左、右顺序依次行走新增的独立闭环，全部完成后再回到主道路。
- 道路卡优先级与等级仍随卡片保存和显示；按最新规则，行走顺序由主道路与拼接闭环队列决定。
- 各拼接闭环都有从起点出发并回到起点的完整行走路线；单点接入的闭环先走到连接点、绕环，再接回主道路。
- 新施工不会中断当前圈：在原主道路上施工，保持当前进度，完成本圈后进入新增闭环；在拼接闭环上施工，先完成当前闭环，回到起点后应用新队列并从主道路开始。
- 完整走完一个阶段才计一圈，途中再次经过起点不会额外计圈、回血或生成首领。
- 所有道路必须连接到主道路，提交时不能遗留只有一个邻接道路的死端。功能卡至少一格需要紧邻道路。
- 施工、拖牌、查看详情、手动暂停、结算时都暂停模拟。移动、战斗和触发在同一模拟时钟下推进。
- 手动暂停与施工暂停独立；如果施工前已手动暂停，提交或回滚不会解除手动暂停。
- 原道路允许被新道路卡替换；成功消耗新卡，旧卡不回收；失败连同替换一起回滚。
- 起点、角色当前格与下一步所在格不能被替换；道路和功能地块不能相互覆盖。
- 战斗中可以施工，战斗随施工暂停，提交后继续原战斗。
- 功能地块优先级决定同一位置多个功能的触发顺序，不参与道路选择。
- 同一张多格地块卡每圈最多触发一次，避免把每个格子的效果重复领取。
- 第三个首领首次触发胜利弹窗。继续后不会反复弹窗；后续失败保留本局曾经胜利的记录。

## 原型暂定内容

以下用于可玩演示，策划与聊天没有指定完整细节，可继续调整：

- 1 名角色，9 种初始手牌；地图 14 × 9。
- 起始 16 格闭环，用于留出清晰的绕路构筑空间。
- 卡牌替换不额外收费、不返还旧卡；暂不开放拆除与单独回收。
- 选择卡牌、拖拽与打开详情时提前暂停，方便规划。
- 功能地块通过邻接道路触发，每张每圈一次。
- 首领每两圈出现；生命、攻击、恢复、移动损耗、掉牌概率和手牌上限集中在 `DemoSettings`。
- 金币是收益记录，尚未添加商店或局外养成。
- 本版用图形网格表现角色和战斗，尚未加入角色美术、音效和复杂装备。

## 验证

- `Tools/CoreChecks` 包含 77 项检查：包配置重复键验证、整批提交/回滚、暂停、替换锁、主道路优先、多个闭环方向排序、行走中施工、单点接入闭环、卡牌旋转、战斗掉牌、胜利和继续直到失败。
- 本地有 .NET 10 SDK 时可运行 `dotnet run --project Tools/CoreChecks/CoreChecks.csproj`。
- `Assets/Editor/DemoEditor.cs` 提供 Unity 菜单与 Windows 构建入口。
- `-demo-smoke -demo-output <目录>` 是自动运行截图检查参数；正常启动不需要它们。
